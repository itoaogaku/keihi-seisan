# 経費精算PDF作成アプリ

個人のクレジットカード明細から、会社ごとの経費精算PDFを作成し、
Googleスプレッドシートに保存できるWebアプリです。

## 1. システム構成

サーバー側にDBを持たず、各ユーザーのGoogleスプレッドシート宛にブラウザから
直接データを送る構成にすることで、共通の1つのURLを同僚と共有しても
データが混ざらないマルチテナント構成を実現しています。

```
                共通のURL (Vercel)
                        │
        ┌───────────────┴───────────────┐
        │        Next.js アプリ           │
        │  (フロントエンドのみ・DBなし)     │
        └───────────────┬───────────────┘
                         │ ブラウザのlocalStorageに
                         │ 「自分のGAS URL」を保存
        ┌────────────────┼────────────────┐
        │                │                │
   自分のブラウザ      同僚Aのブラウザ    同僚Bのブラウザ
        │                │                │
        ▼                ▼                ▼
  自分のGAS URL      同僚AのGAS URL   同僚BのGAS URL
        │                │                │
        ▼                ▼                ▼
  自分のスプレッドシート 同僚Aのシート    同僚Bのシート
```

- **フロントエンド(Next.js, Vercelにデプロイ)**: CSV取り込み・仕分け・集計・PDF出力を担当。
- **設定(接続設定)**: 各ユーザーが自分のGAS WebアプリURLをブラウザのlocalStorageに保存。
- **バックエンド(GAS)**: 確定した経費データをPOSTで受け取り自分のスプレッドシートに追記する処理と、
  保存済みデータをGETで一覧取得する処理(`?action=list`)を持つ薄い層。
- **データベース**: 各ユーザー自身のGoogleスプレッドシート(サーバー側は一切保持しない)。

## 2. 画面設計(ワイヤーフレーム)

### メイン画面 `/`

```

│ 経費精算PDF作成                           [⚙ 設定] │
├───────────────────────────────────────────────────┤
│ 1. 明細の取り込み                                    │

├───────────────────────────────────────────────────┤
│ 2. 集計期間(締め日)の設定                            │
│  締め日:[15] 対象年月:[2026-08] → 期間: 07/16〜08/15  │
├───────────────────────────────────────────────────┤
│ 明細の仕分け             全32件  未仕分け 5件         │
│ ┌──┬──────┬────┬───────┬──────┬───────┬──────────┬──┐ │
│ │☑│利用日 │方法│ 内容   │ 金額  │ メモ  │仕分け(選択)│  │ │
│ ├──┼──────┼────┼───────┼──────┼───────┼──────────┼──┤ │
│ │☑│08/01 │カード│〇〇文具│¥3,200│[___] │[組織A ▼] │🗑│ │
│ │☐│08/02 │現金 │タクシー│¥1,500│[ - ] │[除外   ▼] │🗑│ │
│ │ …                                                  │ │
│ └───────────────────────────────────────────────┘ │
│           [ 選択した1件を出張報告書へ転記 ]           │
├───────────────────────────────────────────────────┤
│ 3. 集計結果                                          │
│   合計請求額: ¥XX,XXX                                │
│   [組織A: ¥.. ] [組織B: ¥.. ] [組織C: ¥.. ] [組織D]  │
├───────────────────────────────────────────────────┤
│ 4. PDF出力・保存                                     │
│   発行日:[____]  備考:[____]                         │
│   [ 経費精算PDFを出力(確定) ]  [ スプレッドシートに一時保存 ] │
└───────────────────────────────────────────────────┘
```

「経費精算PDFを出力」は確定操作として、スプレッドシートへの保存とPDF作成をまとめて行います
(保存に失敗した場合はPDFも作成されません)。まだ確定しない下書き段階のデータは
「スプレッドシートに一時保存」で残しておけます。

メモ欄は、請求先を「除外」にすると自動的に「-」表示になり編集できなくなります
(プライベート決済にはメモが不要なため)。それ以外の請求先を選んだときは、
過去に確定・一時保存した明細の中に同じ「内容」のものがあれば、そのメモを自動的に引き継ぎます。

各行のチェックボックスで明細を選び「選択した◯件を出張報告書へ転記」を押すと、
出張報告書タブ(下記)の出張経費欄にその内容(日付・内容・金額・メモ→備考)が
そのまま追加されます(「除外」に仕分けた明細は転記対象外)。

│                                  [更新] [CSVで書き出す]│
│ ┌──────┬──┬────┬────┬────┬────────┬──────┬────┬──────┐ │

│ ├──────┼──┼────┼────┼────┼────────┼──────┼────┼──────┤ │

「発行日で絞り込み」は、確定・一時保存の際に指定した発行日ごとに一覧を切り替えて表示します。
「CSVで書き出す」は、絞り込み後も含めて一覧に表示されている内容をそのままCSVファイルとしてダウンロードします。

### 出張報告書画面 `/business-trip-report`

経費精算PDF作成画面でチェックした明細を出張経費として転記できる、独立したタブです。

## 3. 使い方

1. カード会社サイトからダウンロードしたCSV(または明細のコピペ)を取り込む。現金決済は「現金決済の追加」から1件ずつ追記する。
2. 締め日と対象年月を指定し、集計期間を確認する。
3. 各明細の「仕分け」列で請求先組織(または「除外」)を選択する。必要に応じてメモも入力する。
4. 集計結果を確認し、発行日を指定する(デフォルトは当日)。
   - 途中経過を残したいだけなら「スプレッドシートに一時保存」を使う(PDFは作らない)。
   - 内容が確定したら「経費精算PDFを出力」を押す。これは確定操作として、
     スプレッドシートへの保存とPDF作成をまとめて行う
     (初回は「設定」画面でのGAS URL登録が必要。手順は [`gas/README.md`](./gas/README.md) を参照)。
5. 「履歴」タブでは、保存済みの全データを期間の絞り込みなしで一覧表示できる。
   発行日で絞り込んだり、一覧の内容をそのままCSVファイルとして書き出せる。
6. 出張に伴う経費がある場合、明細表でチェックを入れて「選択した明細を出張報告書へ転記」
   を押すと、「出張報告書」タブに経費として転記される。日時・場所・目的・報告内容を入力し、
   「出張報告書のPDFを出力」で1枚のPDFとして出力できる。

CSVの列名はカード会社ごとに異なりますが、`利用日`/`ご利用日`/`日付`、
`利用店名`/`摘要`/`内容`、`利用金額`/`金額` などの一般的な表記を自動認識します。
認識できるヘッダーが見つからない場合は「先頭列から日付・内容・金額」とみなして読み込みます。

## 4. 技術構成

| 領域 | 技術 |
| --- | --- |
| フロントエンド | Next.js 14 (App Router) + TypeScript + Tailwind CSS |
| UIコンポーネント | shadcn/ui スタイルの自前実装コンポーネント |
| CSV解析 | PapaParse |
| PDF出力 | jsPDF + html2canvas(ブラウザ描画をそのまま画像化するため、日本語フォント埋め込みが不要) |
| バックエンド | Google Apps Script(Webアプリとしてデプロイ、ユーザーごとに個別) |
| データベース | 各ユーザー自身のGoogleスプレッドシート |
| ホスティング | Vercel |

## 5. セットアップ・開発

```bash
npm install
npm run dev       # http://localhost:3000
npm run build     # 本番ビルド確認
```

### Vercelへのデプロイ

このリポジトリをVercelにインポートしてデプロイするだけで動作します。
サーバー側の環境変数やDB設定は不要です(GAS URLは各ユーザーのブラウザに保存されるため)。

### 同僚が使い始めるとき

1. VercelのURLにアクセスする。
2. [`gas/README.md`](./gas/README.md) の手順で、自分のスプレッドシート宛にGASをデプロイする。
3. アプリの「設定」画面で発行されたGAS URLを登録する。

これにより、共通のURLを使いながらも、各自のデータは各自のスプレッドシートにのみ保存されます。
